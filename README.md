🌐 Personal Portfolio Website

👨‍💻 About

This is my personal portfolio website, created to showcase my skills, projects, education, achievements, and professional journey as a Computer Science Engineering student and aspiring Software Engineer.

The website focuses on a clean, modern, responsive UI and provides an easy way for recruiters, developers, and visitors to learn more about me and explore my work.

💻 Getting Started

1. Clone the Repository

git clone https://github.com/ishupal02/ishupalportfolio.git

2. Navigate to the Project

cd ishupalportfolio

3. Run the Website

Open "index.html" directly in your browser.

You can also use Live Server in VS Code for development.
